## ตัวแปร (Variables)
**ตัวแปร (Variables)** คือ ชื่อที่กำหนดขึ้นเพื่อใช้อ้างอิงค่าข้อมูลบนหน่วยความจำ ซึ่งค่าข้อมูลนี้สามารถนำเรียกไปใช้ในโปรแกรมได้ ทั้งนี้กการประกาศชื่อตัวแปรขึ้นใช้งานจะเป็นตามกฎการตั้งการตั้งชื่อ

## **1.การกำหนดตัวแปร**

**รูปแบบการสร้างตัวแปร**

``` python lines
ชื่อตัวแปร = ค่าที่ต้องการกำหนดให้ตัวแปร
```

### **การกำหนดค่าให้ตัวแปรหลายตัว**
``` python lines
a = b = c = 10
```
หมายถึงกำหนดให้ตัวแปร `a` `b` และ `c` อ้างอิงไปยังตำแหน่งหน่วยความจำที่เก็บค่าข้อมูลเลขจำนวนเต็ม `10` อยู่

``` python lines
a, b, c = 10, 20, "Hello"
```
หมายถึง กำหนดตัวแปร `a` และ `b` อ้างอิงไปถึงตำแหน่งบนหน่วยความจำที่เก็บค่าตัวเลขจำนวนเต็ม `10` และ `20` ตามลำดับ และกำหนดตัวแปร c อ้างอิงไปยังข้อมูลประเภท `String`
``` python lines
num1 = "123"
num2 = 123
print(num*2)
name_ball
```

## **2.ชื่อตัวแปร (Variable names)**
นักเขียนโปรแกรมมักจะเลือกชื่อตัวแปรที่มีความหมาย เพื่อบ่งบอกว่าตัวแปรนั้นใช้เพื่ออะไร
* ชื่อตัวแปรสามารถยาวเท่าใดก็ได้ตามที่ต้องการ
* สามารถมีได้ทั้งตัวอักษรและตัวเลข แต่ ไม่สามารถเริ่มต้นด้วยตัวเลข ได้
* การใช้อักษรตัวพิมพ์ใหญ่เป็นสิ่งที่ทำได้ตามกฎแต่ตามทำเนียมแล้วนิยมใช้ตัวพิมพ์เล็กสำหรับชื่อตัวแปร
* อักขระขีดล่าง `_` สามารถปรากฏในชื่อได้ และมักใช้ในชื่อที่มีหลายคำ เช่น `your_name`
* `76trombones` ผิดกฎเพราะเริ่มต้นด้วยตัวเลข
* `more@` *ผิดกฎเพราะมีอักขระ* `@` ที่ไม่ถูกต้อง
* คำบางคำถูกสงวนไว้สำหรับใช้ในไวยากรณ์ของภาษา Python `(เช่น class, def, while)` ซึ่งเรียกว่า **คำสงวน (keywords)**, คำสงวนเหล่านี้ไม่สามารถใช้เป็นชื่อตัวแปรได้ เนื่องจากตัวแปลภาษาใช้คำสงวนเหล่านี้ในการจดจำโครงสร้างของโปรแกรม
หากคุณตั้งชื่อตัวแปรไม่ถูกต้อง คุณจะได้รับ ข้อผิดพลาดทางไวยากรณ์ (syntax error)

---

### **กฎ 7 ข้อที่ต้องจำ**

1. **ตัวแรกต้องไม่ใช่ตัวเลข:** ชื่อต้องขึ้นต้นด้วย ตัวอักษร `(a-z, A-Z)` หรือ `underscore (_)` เท่านั้น
    * `name`, `_addr`, `myVar`
    *  `1name` (ห้ามขึ้นต้นด้วยเลข)

2. **ใช้ Underscore คั่นคำ (Snake Case):** หากชื่อยาวมากกว่า 1 คำ นิยมให้คั่นด้วย `_` เพื่อให้อ่านง่าย
    *  `total_price`, `student_score`

3. **ห้ามมีสัญลักษณ์พิเศษ:** ชื่อประกอบด้วย ตัวอักษร, ตัวเลข และ `_` เท่านั้น ห้ามมีสัญลักษณ์อื่นๆ เช่น `+`, `-`, `*`, `/`, `%`, `=`, `@`, `$`, `Spacebar`
    *  `my_addr1`, `var_2`
    * `my-addr` (ห้ามใช้ขีดกลาง), `user name` (ห้ามเว้นวรรค)

4. **ห้ามซ้ำกับคำสงวน (Keywords):** ห้ามตั้งชื่อซ้ำกับคำสั่งหลักของ Python
    *  `if`, `else`, `for`, `while`, `class`

5. **ตัวเล็ก-ตัวใหญ่ ไม่เหมือนกัน (Case-Sensitive):** อักษรตัวพิมพ์ใหญ่และเล็กถือเป็นคนละตัวกัน
    *  `score`, `Score`, และ `SCORE` คือตัวแปรคนละตัวกัน

6. **ความยาวไม่จำกัด:** ชื่อจะยาวเท่าไหร่ก็ได้ (แต่ควรยาวพอประมาณให้อ่านรู้เรื่อง)

7. **ชื่อควรสื่อความหมาย:** ตั้งชื่อให้รู้ว่าเก็บค่าอะไร อ่านแล้วเข้าใจทันที
    *  `pi = 3.14`
    *  `score = 100`

## 3. การใชัฟังก์ชัน `input()` รับข้อมูลเก็บลงในตัวแปร

เมื่อใช้ฟังก์ชัน `input()` รับค่าข้อมูลจากผู้ใช้งานโปรแกรม เราสามารถนำค่านั้นมาจัดเก็บลงในตัวแปรได้


```  python lines
ตัวแปร = input("ข้อความที่จะแสดงค่าก่อนรับข้อมูล")
```

เช่น
```  python lines
age = input("How old are you? :")
```
หมายถึง รับข้อมูลอายุจากผู้ใช้งานโปรแกรม แล้วนำค่าข้อมูลนั้นมาจัดเก็บลงในตัวแปร age ซึ่งจะมีผลทำให้ตัวแปร age อ้างอิงไปยังค่าอายุที่ผู้ใช้กรอกเข้ามา

---
### การใช้ฟังก์ชัน `print()` แสดงค่าตัวแปรออกทางจอภาพ

เราสามารถใช้ฟังก์ชัน `print()` แสดงค่าตัวแปรออกทางจอภาพได้


``` python lines
print(ชื่อตัวแปร)
```
``` python lines
name = "Aekkarat"
print("Name"," "+name)
price = 100
print(price)
```
ในกรณีที่มีข้อความที่ต้องการแสดงผลร่วมกับค่าของตัวแปร สามารถเรียกใช้งานฟังก์ชัน `print()`


``` python lines
print(ข้อความที่ต้องการแสดง, ชื่อตัวแปร)
```

## 4.การเปลี่ยนแปลงค่าของตัวแปร

เมื่อมีการกำหนดค่าให้กับตัวแปร ตัวแปรนั้นก็จะถูกสร้างขึ้นพร้อมทั้งทั้งถูกกำหนดชนิดข้อมูลให้โดยอัตโนมัติตามข้อมูลที่ตัวแปรนั้นอ้างอิงอยู่

แต่หากต่อมามีการกำหนดค่าใหม่ให้กับตัวแปร ชนิดข้อมูลของตัวแปรนั้นก็จะเปลี่ยนแปลงไปตามค่าใหม่ที่กำหนดให้
``` python lines
x = 100
print(x)
y = x
print(y)
y = 200
print(y)
print(y)
y = "abc"
print(y)
print(y)
```

## **5. ชนิดข้อมูล Data Type**

ชนิดข้อมูล คือ สิ่งที่ได้จากกำหนดลักษณะและขอบเขตของข้อมูลนั้น ๆ โดยข้อมูลที่มีชนิดของข้อมูลแตกต่างกัน ชนิดข้อมูลบน Python มี 7 ประเภทด้วยกัน

### **ชนิดข้อมูลตัวเลข (Numeric)**
Numeric เป็นชนิดข้อมูลประเภทตัวเลข แบ่งออกได้เป็น `3 ประเภท`

1. **Integer**
```
123, 0
```
2. **Floating point**
``` 
-123.00, 1.2, 3.0
```
3. **Boolean**
``` 
True, False
```

---

### **จำนวนเต็ม (Integers)**
เป็นชนิดข้อมูลเลขจำนวนเต็มบวกหรือลบ จะเป็นเลขฐานสิบ เลขฐานสอง

1. **เลขฐานสิบ**
``` python lines
10
-11
```
2. **เลขฐานสอง**
``` python lines
0b1010
-0b1010
```
3. **เลขฐานแปด**
``` python lines
0o12
-0o13
```
4. **เลขฐานสิบหก**
``` python lines
0xA
-0xB
```

<Note> 
**เกร็ดความรู้**: เลขฐานต่างๆ Python รองรับการเขียนเลขฐานอื่นนอกจากฐานสิบ
* **ฐานสอง**: 0b1010 (ใช้ bin() แปลง)
* **ฐานแปด**: 0o12 (ใช้ oct() แปลง)
* **ฐานสิบหก**: 0xA (ใช้ hex() แปลง) 
</Note>

 ---

### **จำนวนทศนิยม** (Floating point numbers)
เป็นชนิดข้อมูลแบบเลขทศนิยมหรือเรียกว่า `เลขจำนวนจริง (Real number)` เช่น 10.0, 15.33, 20,000,22.99e2

### จำนวนเซิงซ้อน (Complex numbers)
เป็นชนิดข้อมูลแบบเลขจำนวนเชิงซ้อน โดยเลขจำนวนเชิงซ้อนเกิดจากการนำจำนวนจริง (Real) และจำนวนจินตภาพ (Imaginary) มารวมกัน


```
-4.5+2j -4.5 ว่าเป็นส่วนของเลขจำนวนจริง
```
## **6.ชนิดข้อมูลตรรกะ** (Boolean)

เป็นชนิดข้อมูลที่มีเพียง 2 ค่า คือ True และ False
```
print(2<3)
print(7>9)
```

```

```
