## **1.ฟังก์ชันรับข้อมูล** `input()`

ฟังก์ชันรับข้อมูล `input()`ใน Python จะทำหน้าที่รับข้อมูลจากผู้ใช้งานโปรแกรมเข้ามาทางคีย์บอร์ดรูปแบบของฟังก์ชันของ`input()`


รับข้อมูลด้วยฟังก์ชัน input()

*เช่น*
```python lines
input("Please input score")
```


การรับค่า `input()` รูปแบบเก็บค่าตัวแปร
*เช่น*
```python lines
age = input("How old are you :")
```

## **2.แสดงผลข้อมูลด้วยฟังก์ชัน** `print()`

ฟังก์ชัน `Print()` ใน Python จะทำหน้าที่แสดงผลค่าของข้อมูลออกทางจอภาพหรืออุปกรณ์แสดงผลต่าง ๆ ในรูปแบบของฟังก์ชัน `Print()`

เช่น

```python lines
print(data1,data2)
```
และ
```python lines
print(data1,data2+...+Data3)
```
```python lines
print("I love python")
print("I love Master ball")
print("I love python,123")
print("I love python"+123)
```
---
การแสดงผล `Print()`โดยใช้ตัวคั่น `|` และ `-` ในการแสดงผลข้อมูล

`sep=` คือตัวคั่นการแสดงผลข้อมูล

```python lines
print("Data1","Data2","Data3 ",sep="|" )
```
```python lines
print("Vanila","Strawberry","Chocolate ","Chocolate ",end="|" )
```
