## **1. ภาษาคอมพิวเตอร์คืออะไร?**
มนุษย์เราสื่อสารกันด้วย "ภาษามนุษย์" แต่คอมพิวเตอร์ไม่เข้าใจภาษานั้น เพื่อให้เราสั่งงานคอมพิวเตอร์ได้ เราจึงต้องใช้ **"ภาษาคอมพิวเตอร์"**
ประวัติความเป็นมาของภาษา Python

* ปี 1989: Guido van Rossum นักวิทยาศาสตร์คอมพิวเตอร์ชาวดัตช์ (เนเธอร์แลนด์) ได้เริ่มทำงานเกี่ยวกับภาษาโปรแกรมมิ่งภาษาใหม่ที่อ่านและเขียนได้ง่าย เขาตั้งชื่อตามชื่อ Flying Circus ของ Monty Python ซึ่งเป็นรายการตลกของอังกฤษที่เขาชอบดู
* ปี 1991: เวอร์ชันแรกของ Python คือ เวอร์ชัน 0.9.0 ได้รับการเผยแพร่ออกมาและมีฟีเจอร์หลายอย่างที่ยังคงมีอยู่ใน Python เวอร์ชันใหม่ เช่น Class Inheritance, Exception Handling และ Modules
* ปี 1994: Python 1.0 เปิดตัว มีฟีเจอร์ใหม่ ๆ เช่น Lambda, Filter, Map และ Reduce ซึ่งทำให้โปรแกรมทำงานได้ง่ายขึ้น นอกจากนี้ยังเพิ่มการรองรับโมดูล ซึ่งอนุญาตให้โปรแกรมเมอร์จัดระเบียบโค้ดของตนเองเป็นไฟล์แยกต่างหาก
* ปี 2000: Python 2.0 เปิดตัว ฟีเจอร์ใหม่ ๆ ที่เพิ่มเข้ามาในเวอร์ชันนี้ เช่น List Comprehension, Garbage Collector และการสนับสนุน Unicode
* ปี 2008: Python 3.0 เปิดตัว Python โดยเวอร์ชันนี้เป็นการอัปเดตครั้งใหญ่ก็ว่าได้ ซึ่งจะไม่รองรับการทำงานแบบย้อนกลับกับเวอร์ชันก่อนหน้า และยังได้ลบฟีเจอร์หลายอย่างที่ถือว่าซ้ำซ้อน (redundant) หรือทำให้ผู้ใช้สับสนออกไป และได้นำเอาฟังก์ชันในปัจจุบันของ Python เข้ามาใช้ในเวอร์ชันนี้ ซึ่งฟังก์ชันที่ว่านี้ก็คือ "print( )" ซึ่งสาวกไพธอนหรือคนที่ใช้งานอยู่คงรู้จักกันดีครับ ทำให้การเขียนโค้ดทั้งใน Python 2 และ 3 ได้ง่ายขึ้น


**Python** จัดเป็นภาษาคอมพิวเตอร์ **ระดับสูง (High-Level Language)**
* **อ่านง่าย:** มีโครงสร้าง (Syntax) คล้ายภาษาอังกฤษ
* **เขียนง่าย:** ไม่ต้องกังวลเรื่องฮาร์ดแวร์ซับซ้อน (เช่น การจองหน่วยความจำ) เหมือนภาษาคอมพิวเตอร์ยุคเก่า

## **2. โปรแกรมคืออะไร? (What is a program?)**
โปรแกรม คือ ลำดับของคำสั่งที่ระบุวิธีการดำเนินการคำนวณ การคำนวณนี้อาจเป็นเรื่องทางคณิตศาสตร์ (เช่น การแก้ระบบสมการ) หรือเป็นการคำนวณเชิงสัญลักษณ์ (เช่น การค้นหาและแทนที่ข้อความในเอกสาร หรือการประมวลผลภาพ/เล่นวิดีโอ)
รายละเอียดของคำสั่งอาจแตกต่างกันไปตามภาษา แต่คำสั่งพื้นฐานบางอย่างมีอยู่ในแทบทุกภาษา

การเขียนโปรแกรมสามารถคิดได้ว่าเป็นกระบวนการในการแบ่งงานที่ซับซ้อนใหญ่ ๆ ออกเป็นงานย่อย ๆ ที่เล็กลงเรื่อย ๆ จนกระทั่งงานย่อยนั้นง่ายพอที่จะดำเนินการด้วยคำสั่งพื้นฐานเหล่านี้ได้

## **5. ตัวแปรภาษา Python (Python interpreter)**
 คือโปรแกรมที่อ่านและดำเนินการโค้ด `Python` เมื่อเริ่มทำงาน คุณจะเห็นผลลัพธ์ที่ระบุเวอร์ชัน (ตรวจสอบว่าเริ่มต้นด้วย '3') บรรทัดสุดท้ายจะเป็น พร้อมท์ (prompt) (>>>) ซึ่งบ่งชี้ว่าตัวแปลภาษาพร้อมให้คุณป้อนโค้ดแล้ว หากคุณพิมพ์โค้ดหนึ่งบรรทัดแล้วกด Enter ตัวแปลภาษาจะแสดงผลลัพธ์ (เช่น >>> 1 + 1 จะให้ผลลัพธ์เป็น 2)

## **6. ตัวดำเนินการทางคณิตศาสตร์ (Arithmetic operators)**
Python มี ตัวดำเนินการ (operators) ซึ่งเป็นสัญลักษณ์พิเศษที่ใช้แทนการคำนวณ
สัญลักษณ์ | ความหมาย | ตัวอย่าง | ผลลัพธ์
| :---: | :---: | :--- |:--- |
| + | บวก | 10 + 2 | 12 
|- | ลบ| 10 - 2,8
|* | คูณ,10 * 2 | 20
|/ | หาร (ผลลัพธ์มีทศนิยมเสมอ) | 84 / 2 | 42.0
|** | ยกกำลัง | 6 ** 2 | 36

<Warning> 
ระวังสับสน! ใน Python เครื่องหมาย ^ ไม่ใช่ การยกกำลัง แต่คือ XOR (Bitwise Operator)
