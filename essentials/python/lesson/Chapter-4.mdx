Operator ในภาษา Python คือสัญลักษณ์หรือคำสงวนที่ใช้สำหรับการดำเนินการทางคณิตศาสตร์ การเปรียบเทียบ และการกำหนดค่า ตัวอย่างเช่น

```python
x = 10
y = 5

print(x + y)
print(x > y)
```

ในตัวอย่างนี้ `+` และ `>` คือ operator ที่ใช้สำหรับการบวกและการเปรียบเทียบค่าตามลำดับ

---

## 1. ประเภทของ Operators

ใน Python แบ่ง Operator ออกเป็น 7 กลุ่มหลัก ดังนี้:

---

### 1.1 Arithmetic Operators (ตัวดำเนินการทางคณิตศาสตร์)

| สัญลักษณ์ | ความหมาย | ตัวอย่าง | ผลลัพธ์ |
|:---:|:---:|:---|:---:|
| `+` | บวก | `10 + 3` | `13` |
| `-` | ลบ | `10 - 3` | `7` |
| `*` | คูณ | `10 * 3` | `30` |
| `/` | หาร (ผลลัพธ์เป็น float เสมอ) | `10 / 3` | `3.33...` |
| `%` | หารเอาเศษ (Modulo) | `10 % 3` | `1` |
| `**` | ยกกำลัง | `10 ** 3` | `1000` |
| `//` | หารปัดเศษทิ้ง (Floor Division) | `10 // 3` | `3` |

```python
x = 10
y = 3

print(x + y)   # Output: 13
print(x - y)   # Output: 7
print(x * y)   # Output: 30
print(x / y)   # Output: 3.3333333333333335
print(x % y)   # Output: 1
print(x ** y)  # Output: 1000
print(x // y)  # Output: 3
```

---

### 1.2 Assignment Operators (ตัวดำเนินการกำหนดค่า)

ใช้สำหรับกำหนดค่าลงในตัวแปร เช่น =, +=, -=, *=, /=, %=, **=, //=

```python
x = 5
x += 3  # equivalent to x = x + 3
print(x)  # Output: 8

y = 10
y //= 3  # equivalent to y = y // 3
print(y)  # Output: 3
```

---

### 1.3 Comparison Operators (ตัวดำเนินการเปรียบเทียบ)

```python
x = 5
y = 3

print(x == y)  # Output: False
print(x != y)  # Output: True
print(x > y)   # Output: True
print(x < y)   # Output: False
print(x >= y)  # Output: True
print(x <= y)  # Output: False
```

---

### 1.4 Logical Operators (ตรรกะ)

```python
x = 5
y = 3

print(x > 3 and y < 5)  # True
print(x > 3 or y > 5)   # True
print(not(x > 3))       # False
```

---

### 1.5 Identity Operators (ตรวจสอบอัตลักษณ์ของวัตถุ)

```python
x = ["apple", "banana"]
y = ["apple", "banana"]
z = x

print(x is z)  # True
print(x is y)  # False
print(x == y)  # True
```

---

### 1.6 Membership Operators (ตรวจสอบการเป็นสมาชิก)

```python
x = ["apple", "banana"]

print("banana" in x)  # True
print("cherry" in x)  # False
```

---

### 1.7 Bitwise Operators (ระดับบิต)

```python
x = 10  # Binary: 1010
y = 4   # Binary: 0100

print(x & y)  # 0
print(x | y)  # 14
print(x ^ y)  # 14
print(~x)     # -11
print(x << 2) # 40
print(x >> 2) # 2
```
