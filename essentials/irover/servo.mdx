## ⚙️ รู้จักกับเซอร์โวมอเตอร์ (Servo Motor)

**เซอร์โวมอเตอร์** คือมอเตอร์ที่สามารถสั่งงานให้หมุนไปยัง "องศา" ที่ต้องการได้อย่างแม่นยำ โดยรุ่นมาตรฐานที่ใช้กับ iROVER จะมีมุมหมุนจำกัดที่ **0 ถึง 180 องศา**

### จุดต่อสายและขั้ว (Pinout)
สายไฟของเซอร์โวมอเตอร์จะมี 3 เส้น ต้องเสียบให้ถูกช่องและถูกทิศทาง



[Image of servo motor wiring diagram]


| สีสายไฟ | สัญลักษณ์ | หน้าที่ |
| :--- | :---: | :--- |
| 🟤 **น้ำตาล (หรือดำ)** | `GND (-)` | กราวด์ (Ground) |
| 🔴 **แดง** | `VCC (+)` | ไฟเลี้ยง (Power 5V) |
| 🟠 **ส้ม (หรือขาว)** | `Signal (S)` | สัญญาณควบคุม |

<Warning>
**ข้อควรระวัง:** ห้ามเสียบสายกลับด้าน หรือเสียบผิดช่อง เพราะอาจทำให้มอเตอร์หรือบอร์ดควบคุมเสียหายได้ทันที
</Warning>

## 💻 คำสั่งควบคุม (Command)

เราใช้คำสั่ง `i.servo()` เพื่อกำหนดตำแหน่งของแขนเซอร์โว

### รูปแบบคำสั่ง
```python lines
i.servo(ขาพอร์ต, องศา)
```

* **ขาพอร์ต:** ระบุขาที่เสียบบนบอร์ด iKB-1 (เช่น 10, 11, 12)
* **องศา:** ระบุตำแหน่งมุมที่ต้องการ (0 ถึง 180)

### สั่งให้ Servo ที่ขา 10 หมุนไปที่ 0 องศา (สุดฝั่งหนึ่ง)
```python lines
i.servo(10, 0)
```
### สั่งให้ Servo ที่ขา 10 หมุนไปที่ 180 องศา (สุดอีกฝั่ง)
```python lines
i.servo(10, 180)
```
### สั่งให้ Servo ที่ขา 10 มาอยู่ตรงกลาง
```python lines
i.servo(10, 90)
```

## Mini Project: ที่ปัดน้ำฝน (Servo Sweep)
ลองเขียนโปรแกรมสั่งให้ Servo หมุนไปและกลับอย่างต่อเนื่อง เหมือนที่ปัดน้ำฝนรถยนต์
```python lines
from irover import *
from time import sleep

i = IROVER()

while True:
    # 1. ปัดไปทางขวา (0 องศา)
    i.servo(10, 0)
    sleep(1)  # รอให้มอเตอร์หมุนไปถึงที่หมายก่อน
    
    # 2. ปัดไปทางซ้าย (180 องศา)
    i.servo(10, 180)
    sleep(1)  # รอ
```

<Note> 
Tips: หากต้องการให้ Servo หมุนช้าๆ (Smooth) เราไม่สามารถสั่งข้ามจาก 0 ไป 180 ได้ทันที ต้องใช้ for loop เพื่อสั่งขยับทีละนิด เช่น ทีละ 1 องศา แล้วหน่วงเวลาสั้นๆ 
</Note>
