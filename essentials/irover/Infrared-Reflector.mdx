## รู้จักกับ ZX-03

**ZX-03** คือเซนเซอร์ที่ใช้แสงอินฟราเรดในการตรวจจับความเข้มของสีบนพื้น โดยอาศัยหลักการ **การสะท้อนของแสง (Reflection)**
* **พื้นสีขาว:** สะท้อนแสงได้ดี -> ค่าที่อ่านได้จะ **น้อย**
* **พื้นสีดำ:** ดูดกลืนแสง (ไม่สะท้อน) -> ค่าที่อ่านได้จะ **มาก**

## การติดตั้งและเชื่อมต่อ (Installation)

### 1. ตำแหน่งการติดตั้ง (Mounting)
ตำแหน่งของเซนเซอร์มีความสำคัญมากที่สุดต่อความแม่นยำในการเดินตามเส้น

  style={{ borderRadius: '0.5rem' }}
  src="/images/6.png"
/>


<Warning>
**ระยะห่างที่เหมาะสม (The Sweet Spot)**
ต้องติดตั้งเซนเซอร์ให้สูงจากพื้นระหว่าง **5 - 15 มิลลิเมตร**
* ❌ **ถ้าใกล้เกินไป:** หัวเซนเซอร์อาจชนพื้น หรืออ่านค่าผิดพลาด
* ❌ **ถ้าห่างเกินไป:** แสงอินฟราเรดจะกระจายหายไป ทำให้แยกสีขาวกับดำไม่ออก
</Warning>

### 2. การเชื่อมต่อสาย (Wiring)
สำหรับหุ่นยนต์ iROVER แนะนำให้เชื่อมต่อที่พอร์ต Analog บนบอร์ด IPST-WiFi ดังนี้:

| เซนเซอร์ | พอร์ตบน IPST-WiFi | หน้าที่ |
| :--- | :---: | :--- |
| **ZX-03 ตัวที่ 1** | `Pin 33` | สำหรับตรวจจับด้านซ้าย (หรือขวา) |
| **ZX-03 ตัวที่ 2** | `Pin 34` | สำหรับตรวจจับด้านขวา (หรือซ้าย) |

## การเขียนโปรแกรมทดสอบ (Testing)

ก่อนจะเขียนโค้ดเดินตามเส้น เราต้องเขียนโค้ดเพื่อ **"ดูค่า (Read Value)"** ของสีขาวและสีดำในสนามจริงก่อน

```python lines
from irover import *
from time import sleep

i = IROVER()

while True:
    # อ่านค่าจาก Pin 33 และ 34
    # ใช้ analog(พอร์ต) จะได้ค่าช่วง 0 - 1023
    s1 = i.analog(33)
    s2 = i.analog(34)
    
    # แสดงค่าขึ้นจอ OLED
    i.fill(0)
    i.text("Sen 33: %d" % s1, 0, 10)
    i.text("Sen 34: %d" % s2, 0, 25)
    i.show()
    
    sleep(0.1)
```
## เทคนิคการหาค่ากลาง (Threshold)
<Steps>

    <Step title="1. อ่านค่าสีขาว">
        วางเซนเซอร์บนพื้นสีขาว แล้วจดค่าไว้  
        (สมมติได้ค่า <code>300</code>)
    </Step>

    <Step title="2. อ่านค่าสีดำ">
        วางเซนเซอร์บนเส้นสีดำ แล้วจดค่าไว้  
        (สมมติได้ค่า <code>900</code>)
    </Step>

    <Step title="3. คำนวณค่ากลาง (Average)">
        นำค่ามารวมกันแล้วหาร 2:<br/><br/>
        $$
    refR = \frac{300 + 900}{2} = \mathbf{600}
    $$
    </Step>

</Steps>

<Tip>
ในการเขียนเงื่อนไข <code>if</code>:<br/><br/>
• ถ้าค่าอ่านได้ &lt; 600 → เจอสีขาว<br/>
• ถ้าค่าอ่านได้ &gt; 600 → เจอสีดำ
</Tip>
