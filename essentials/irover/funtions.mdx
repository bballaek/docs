##ฟังก์ชั่นเคลื่อนที่ของหุ่นยนต์ (Movement)
ชุดคำสั่งสำเร็จรูปสำหรับการควบคุมทิศทาง โดยกำหนดความเร็วได้ตั้งแต่ **0 ถึง 100%**

### 1. เดินหน้าและถอยหลัง (Basic Move)
```python lines
# รูปแบบ: i.fd(speed)
i.fd(50)  # เดินหน้าด้วยความเร็ว 50%
```
```python lines
# รูปแบบ: i.bk(speed)
i.bk(50)  # ถอยหลังด้วยความเร็ว 50%
```
---
### การเลี้ยวและหมุนตัว (Turning)
มีความแตกต่างกันระหว่าง "หมุน (Spin)" และ "เลี้ยว (Turn)" ดังนี้:

<Note> 
ข้อสังเกต:
* **หมุน (Spin - sl/sr)**: หุ่นจะหมุนอยู่กับที่ (ล้อ 2 ข้างหมุนสวนทางกัน) เหมาะสำหรับกลับรถในที่แคบ
* **เลี้ยว (Turn - tl/tr)**: หุ่นจะเลี้ยวโค้ง (ล้อหนึ่งหยุด อีกล้อหนึ่งเดิน) วงเลี้ยวจะกว้างกว่า 
</Note>

### 2. สั่งหมุนตัว (Spin)
```python lines
# หมุนซ้าย (Spin Left)
i.sl(50)

# หมุนขวา (Spin Right)
i.sr(50)
```

### 3. สั่งเลี้ยวโค้ง (Turn)
```python lines
# เลี้ยวซ้าย (Turn Left)
i.tl(50)

# เลี้ยวขวา (Turn Right)
i.tr(50)
```
### 4. ขับเคลื่อนอิสระ (Independent Wheel)
**ควบคุมความเร็วของล้อซ้ายและขวาแยกกัน** เหมาะสำหรับการวิ่งแก้เอียง หรือวิ่งตามเส้นโค้ง
```python lines
# เดินหน้า - แยกความเร็วล้อ (Left Speed, Right Speed)
i.fd2(30, 60)  # ล้อซ้าย 30%, ล้อขวา 60% (หุ่นจะกินซ้าย)

# ถอยหลัง - แยกความเร็วล้อ
i.bk2(30, 60)
```

### 5. การหยุด (Stop)
```python lines
i.stop()  # หยุดมอเตอร์ทุกช่องทันที
```

### สิ่งที่ปรับปรุงให้ดีขึ้น:
1.  **แยกประเภทการเลี้ยว:** ผมแยก `sl/sr` (หมุน) กับ `tl/tr` (เลี้ยว) ออกจากกันชัดเจน พร้อมคำอธิบายใน `<Note>` เพื่อกันความสับสน
2.  **จัดกลุ่ม Code:** ใช้ `<CodeGroup>` ในส่วนเดินหน้า/ถอยหลัง เพื่อประหยัดพื้นที่และดูเปรียบเทียบง่าย
3.  **คำอธิบาย fd2/bk2:** เพิ่มตัวอย่างการใส่ค่าตัวเลข เพื่อให้เห็นภาพว่าใส่ค่าต่างกันแล้วเกิดผลอย่างไรครับ
