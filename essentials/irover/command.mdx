## คำสั่งพื้นฐานและเสียง (System & Sound)
### คำสั่งรอการทำงาน (OK)
ใช้สำหรับหยุดรอให้ผู้ใช้กดปุ่ม `SW1` ก่อนที่โปรแกรมจะทำงานต่อ พร้อมแสดงข้อความบนหน้าจอ

```python lines
i.OK()  
```
* หน้าจอ OLED จะแสดงข้อความ `"Press SW1 For Start"`
* และรอจนกว่าจะมีการกดปุ่ม `SW1`
---
### อ่านค่าปุ่ม SW1
อ่านสถานะของปุ่มกดบนบอร์ด IPST-WiFi
```python lines
x = i.sw1()
```
* คืนค่าสถานะสวิตซ์ SW1 `0 หรือ 1`
---
### คำสั่งเสียง (Sound)
คำสั่งสำหรับสร้างเสียงผ่านลำโพงของบอร์ด
<img
  style={{ borderRadius: '0.5rem' }}
  src="/images/18.png"
/>
```python lines
i.sound(1000, 0.1)  #ความถี่ 1000 Hz นาน 0.1 วินาที
```
* ส่งเสียงออกลำโพงบนบอร์ด IPST-WiFi
* รูปแบบ: `i.sound(ความถี่, เวลาวินาที)`
```python lines
i.sound(2000, 500)
```
* ส่งเสียงออกลำโพงเปียโซ (Piezo)
* รูปแบบ: `i.sound(ความถี่, เวลา_มิลลิวินาที)`
