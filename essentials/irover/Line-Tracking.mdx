## ตรรกะการเดินตามเส้น (Logic Table)

หลักการพื้นฐานของการเดินตามเส้นคือการเปรียบเทียบค่าที่อ่านได้จากเซนเซอร์ซ้ายและขวา กับค่ากลาง (Ref) เพื่อตัดสินใจเคลื่อนที่

จากการหาค่ากลางในบทก่อนหน้า เราสามารถสรุปเงื่อนไขการเคลื่อนที่ได้ดังนี้:

| สถานะเซนเซอร์ซ้าย (L) | สถานะเซนเซอร์ขวา (R) | การกระทำ (Action) |
| :---: | :---: | :--- |
| **> ค่ากลาง (refL)** | **> ค่ากลาง (refR)** | ⬆️ **เดินหน้า (Forward)** |
| **< ค่ากลาง (refL)** | **> ค่ากลาง (refR)** | ↩️ **เลี้ยวซ้าย (Turn Left)** |
| **> ค่ากลาง (refL)** | **< ค่ากลาง (refR)** | ↪️ **เลี้ยวขวา (Turn Right)** |
| **< ค่ากลาง (refL)** | **< ค่ากลาง (refR)** | ➕ **ทางแยก (Intersection)** |

---

## ตัวอย่างโค้ด (Code Implementation)

นำตรรกะจากตารางด้านบนมาเขียนเป็นเงื่อนไข `if-elif-else`


```python lines
from irover import *
i = IROVER()
i.OK()

# กำหนดค่ากลาง (ควรเปลี่ยนตามค่าจริงของสนาม)
refL = 2200
refR = 2200

while True:
    # อ่านค่าเซนเซอร์เก็บลงตัวแปรเพื่อให้โค้ดดูสะอาดตา
    L = i.analog(34)
    R = i.analog(33)

    # 1. เดินหน้า: ซ้ายและขวา เจอค่ามากทั้งคู่
    if L > refL and R > refR:
        i.fd(50)

    # 2. เลี้ยวซ้าย: ซ้ายค่าน้อย (เจอขาว/เส้น) แต่ขวายังค่ามาก
    elif L < refL and R > refR:
        i.tl(40)  # ลดความเร็วลงเพื่อให้เลี้ยวแม่นยำ

    # 3. เลี้ยวขวา: ซ้ายค่ามาก แต่ขวาค่าน้อย (เจอขาว/เส้น)
    elif L > refL and R < refR:
        i.tr(40)

    # 4. เจอทางแยก: ค่าน้อยทั้งคู่ (เจอเส้นตัด)
    else:
        # เลือกทำภารกิจที่ต้องการตรงนี้
        i.stop()
        # หรือสั่งให้เดินข้ามแยก: i.fd(50); sleep(0.5)
```

<Note>
    หมายเหตุ:<br/><br/>
    • ตรรกะ <code>&gt;</code> (มากกว่า) หรือ <code>&lt;</code> (น้อยกว่า) ในตารางนี้ ขึ้นอยู่กับว่า สนามเป็นพื้นสีขาวหรือสีดำ และเส้นเป็นสีอะไร<br/>
    • หากพื้นขาว เส้นดำ: ค่าบนเส้นดำจะสูง (<code>&gt; Ref</code>) และพื้นขาวจะต่ำ (<code>&lt; Ref</code>)<br/>
    • หากพื้นดำ เส้นขาว: ค่าจะกลับกัน<br/><br/>
